Proyecto del 2do sprint

Consiste en mejorar el tiempo en operaciones sobre un arbol binario de busqueda por medio de uso de hilos (usando go).
Se usan 2 arboles para la demostracion, uno bloquedo por un mutex general y otro donde cada nodo contiene un mutex.
Con el archivo 'decidirUnNombre' se pueden hacer pruebas para comparar los tiempos de cada arbol en operaciones como Add o Search.
